🔑 STEP 1: CREATE GITHUB PERSONAL ACCESS TOKEN

1. Go to → https://github.com/settings/tokens/new
2. Log in if prompted
3. Fill in:
   - Token name: CellumaTracker
   - Expiration: 90 days
4. Check these boxes:
   ☑ repo (Full control of repositories)
   ☑ workflow (GitHub Actions)
5. Click "Generate token"
6. COPY the token (long string starting with ghp_)
7. SAVE IT SOMEWHERE SAFE!

═══════════════════════════════════════════════════════════════════════════

📤 STEP 2: PUSH CODE TO GITHUB

Open Terminal and run these commands (one at a time):

Command 1: Configure git with your name
  git config --global user.name "danthebeast"

Command 2: Configure git with your email
  git config --global user.email "your@email.com"
  (Replace with your actual email)

Command 3: Go to the project folder
  cd "/Users/AarraMBP/Desktop/The Prize/Apps/CelluMe"

Command 4: Add the GitHub remote
  git remote add origin https://github.com/danthebeast/celluma-tracker.git

Command 5: Ensure main branch
  git branch -M main

Command 6: Push to GitHub
  git push -u origin main

When Terminal asks for password:
  - Username: danthebeast
  - Password: Paste your token (the long ghp_... string)

Wait for it to finish (shows "Branch 'main' set up to track...")

═══════════════════════════════════════════════════════════════════════════

🌐 STEP 3: DEPLOY WITH VERCEL

1. Go to → https://vercel.com
2. Sign in (use GitHub)
3. Click "New Project"
4. Click "Import Git Repository"
5. Search for "celluma-tracker"
6. Click your repository
7. Click "Import"
8. Vercel auto-detects settings (they're correct!)
9. Click "Deploy"

Wait 2-3 minutes...

Your app is LIVE! 🎉

❓ TROUBLESHOOTING

Problem: "Repository not found"
  → Create GitHub repo first at https://github.com/new
  → Name it "celluma-tracker"

Problem: "Permission denied"
  → Token might be wrong
  → Create a new token and try again
  → Make sure to copy the entire token

Problem: App shows blank page
  → Hard refresh: Cmd+Shift+R (Mac)
  → Check browser console (F12)
  → Check Vercel build logs for errors

Problem: Can't push to GitHub
  → Check token has "repo" scope
  → Check username is "danthebeast"
  → Check you're in the right folder
