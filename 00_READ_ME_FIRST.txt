❓ TROUBLESHOOTING:

"npm: command not found"
  → Install Node.js from nodejs.org

"Port 5173 in use"
  → npm run dev -- --port 3000

"Blank white page"
  → Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)

"Data not saving"
  → Not in private/incognito mode?
  → localStorage enabled?

For more help, check SETUP.md

✨ FEATURES HIGHLIGHT:

Real-time Visualization
  • Heatmaps update instantly as sessions are added
  • Color-coded energy levels (blue → green → orange → red)
  • Shows cumulative J/cm² exposure at each body location

Anatomically Accurate
  • Front/back body views
  • Hand palm maps with finger-level precision
  • Separate ears, nose, mouth panels

Smart Physics
  • Exponential decay over 72 hours
  • ~18-hour half-life for biological accuracy
  • Fluence calculations for each device

Session Management
  • Click to place sessions
  • Drag handles to reposition
  • Double-click or right-click to delete
  • Recent sessions log with timestamps

Data Persistence
  • Automatic saving to localStorage
  • Survives browser restart
  • Export/backup capable
