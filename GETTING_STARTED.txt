WHAT YOU NEED TO DO:

1. Install Node.js (ONE TIME ONLY)
   → Go to https://nodejs.org/
   → Download the LTS (Long Term Support) version
   → Run the installer
   → Takes 5 minutes

2. Open Terminal/Command Prompt
   → Mac: Cmd+Space → type "Terminal" → Enter
   → Windows: Win+R → type "cmd" → Enter

3. Navigate to the app folder
   Copy and paste this:
   
   cd Desktop/The\ Prize/Apps/CelluMe
   
   (On Windows, adjust the path as needed)

4. Run the app
   Copy and paste:
   
   npm install
   npm run dev
   
5. That's it! Your browser will open automatically
   → App loads at http://localhost:5173
   → She can start tracking immediately!

TROUBLESHOOTING:

"npm: command not found"
→ Install Node.js from nodejs.org

"Port 5173 in use"
→ Run: npm run dev -- --port 3000

"Blank white page"
→ Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)

"Data not saving"
→ Make sure not in private/incognito mode
→ Enable localStorage in browser settings
