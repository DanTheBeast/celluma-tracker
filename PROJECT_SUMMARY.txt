KEY FEATURES:
================================================================================

✅ Track 4 devices:
   - Celluma PRO (8 J/cm², 30 min, 16"×8" panel)
   - Celluma POD (6 J/cm², 30 min, 4.4"×2.75" portable)
   - Hooga Torch (22 J/cm², 3 min, 1.25" precision spot)
   - TheraFace Glow (15 J/cm², 12 min, 5"×7" face mask)

✅ Map sessions to:
   - Front/back body views
   - Hand palms (left/right)
   - Face parts (ears, nose, mouth)

✅ Real-time heatmap visualization:
   - Shows cumulative J/cm² exposure
   - Color-coded safety levels (blue→green→yellow→orange→red)
   - Exponential decay over 72 hours (real biology!)

✅ Session management:
   - Drag to reposition
   - Double-click to delete
   - All data saved locally (no server needed)

TECHNOLOGIES USED:
================================================================================

Frontend:
  - React 18 (UI framework)
  - Vite 5 (bundler/dev server)
  - HTML5 Canvas (heatmap rendering)
  - SVG (interactive shapes)
  - localStorage (data persistence)

No external dependencies for core functionality!

Physics & Math:
  - Exponential decay: Q(t) = Q₀ × e^(-t/τ)
  - Fluence calculation: Φ = I × t / 1000
  - Color interpolation: RGB linear gradient
  - Geometric collision detection: Point-in-polygon tests

WHAT TO EDIT:
================================================================================

To modify the app, edit src/App.jsx:

• Add a new device:
  Modify DEVICES object
  
• Change colors:
  Modify HEAT_STOPS array
  
• Adjust physics (decay time, fluence, etc):
  Modify constants (FADE_HOURS, SATURATION_JOULES, etc)
  
• Add new UI elements:
  Modify the return statement in CellumaTracker() component

================================================================================
DATA STORAGE:
================================================================================

All data stored in browser localStorage:
  Key: "celluma-v18"
  Format: JSON array of session objects
  
Each session contains:
  {
    id: timestamp,
    device: "celluma" | "pod" | "torch" | "theraface",
    view: "front" | "back" | "hand-left-palm" | etc,
    x: number,           // Position X
    y: number,           // Position Y
    angle: 0 | 45 | 90 | 135,  // Device rotation
    timestamp: Date.now()
  }

No server, no network calls, no privacy concerns.

================================================================================
TROUBLESHOOTING CHECKLIST:
================================================================================

Port 5173 in use?
  → npm run dev -- --port 3000

npm command not found?
  → Install Node.js from nodejs.org

Blank white page?
  → Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)

Data not saving?
  → Check localStorage enabled in browser
  → Not in private/incognito mode?
  → Try different browser

Build fails?
  → npm cache clean --force
  → rm -rf node_modules
  → npm install
  → npm run build
